## Way 1 — Denominator surgery (prune + rank + metric honesty)

**Idea:** Stop measuring how many SERP titles were ever saved. Retain evidence that can ground claims.

**Triangulation:** internal pipeline (00) · arXiv Less-is-More (11) · multi-doc RAG (12) · Trafilatura (06) · Cohere/Anthropic rerank pattern (07, 10).

**Ship:** prune script + DQS split (`rich_pct_all` / `rich_pct_high_trust` / `rich_pct_deep`). Target high-trust rich ≥70% or all ≥60%.

---

## Way 2 — Numerator attack (fetch budget + Firecrawl + backfill-only ops)

**Idea:** Keep URLs; fill bodies. Prefer `review:backfill-content` over SERP re-enrich.

**Triangulation:** backfill proof (13) · Firecrawl (03) · Jina (04) · Browserless (05) · prior F3 (02).

**Ship:** set `FIRECRAWL_API_KEY`; raise scrape budget 3→15 and full-page limit 10→20 when healthy; ladder local → Jina → Firecrawl → Browserless; ban bulk re-enrich under RL.

**Limit:** Alone unlikely to clear ≥60% while 500+ thin orphans remain — combine with Way 1.

---

## Way 3 — Source-class expansion (specialized corpora)

**Idea:** Write first-class rich rows from review platforms and transcripts.

**Triangulation:** Trustpilot API (08) · youtube-transcript-api (09) · existing direct probes (14).

**Ship:** Phase A free (transcripts + Reddit JSON + probe max + web SERP cap); Phase B Trustpilot API; no Apify/Pushshift without approval.
