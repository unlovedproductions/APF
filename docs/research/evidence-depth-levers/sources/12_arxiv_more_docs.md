# Source 12 — More Documents, Same Length (arXiv 2503.04388)

- **Type:** academic
- **Credibility:** 5
- **URL:** https://arxiv.org/html/2503.04388v1
- **Maps to:** Way 1

## Verbatim / core finding

> …increasing the document count in RAG settings poses significant challenges for LLMs.

> Almost all models perform better when presented with fewer documents, with scores improving by 5% to 10% on average.

(Context length held constant while document count varies.)

## Why it matters

Independent confirmation that **fewer richer docs** beat many thin ones for generation quality — aligns with high-trust DQS split and prune.
