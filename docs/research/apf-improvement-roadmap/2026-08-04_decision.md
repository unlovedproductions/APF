## Executive verdict

**Spend the next 30–90 days on pipeline integrity for Digistore → enrichment → ShadowCast — not on new discovery UI or more marketplaces.**

Binding constraints, in order:

1. **Search/enrichment reliability** (Brave/SearXNG rate limits → 10/10 live Digistore briefs still `complete_degraded`)
2. **Export quality gates** (ShadowCast still accepts degraded briefs)
3. **Scoring calibration** (heuristics without refunds/outcomes; Digistore marketplace already shows EPC/CR/cancel)
4. **Ops hygiene** (Digistore session is already hard-failing correctly; don’t rebuild it first)

APF’s leverage vs AffSync/ProfitSpy-class tools is the **local enrichment → `apf_shadowcast_enriched_v1` handoff**, not browsing. Building another affiliate directory is a **do-not-build**.

## Adversarial pass (Phase 6)

### Four self-critique questions

1. **Are we overfitting to Unloved’s ShadowCast loop?**  
   Yes, deliberately — that’s the product. If APF were sold as a standalone discovery SaaS, H1 would weaken and discovery UX would rise. Flagged.

2. **Did we ignore creative as the real bottleneck?**  
   Opposition is strong for paid-media operators [s18]. Counter: ShadowCast *is* the creative machine; bad briefs raise creative rework cost [s20][s05]. Roadmap still leaves creative cadence to ShadowCast, not APF feature sprawl.

3. **Is Digistore native sort already “good enough” (H2 opposition)?**  
   For human shortlisting, often yes [s09][s18]. APF still re-ranks with a weaker composite — either wire native KPIs honestly or stop claiming Hidden Gem superiority without lift data (**data-insufficient** for “beats native”).

4. **Sample size / recency?**  
   Enrichment live N=10 Digistore; treat rates as directional. Search outage may be transient — refresh_targets require re-measure.

### Steel-man counters retained

- Creative velocity > research depth for many affiliates [s18]
- Digistore official docs: Earnings/sale + cart conversion + cancellation [s18]
- Attrition rarely “technical” [s18] — don’t confuse eng reliability with market churn drivers
